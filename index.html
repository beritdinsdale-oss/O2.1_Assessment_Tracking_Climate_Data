Explore precipitation

Set up the Spring precipitation graph first.

Open xmACIS ↗
1

Choose the tool

Select Single Station → Seasonal Time Series.

2

Choose precipitation

Under Variable, select Precipitation.

3

Choose Spring

Under Period of Interest, select Spring.

4

Choose the station

Under Station Selection, select Search and enter 97331.

Look for Corvallis State University. Entering the ZIP code may not automatically bring up that exact station. Search through the station results until you find Corvallis State University.
5

Include the regression line

Open More Options and select Include Regression Line.

6

Generate the graph

Select Go.

Measure the long-term precipitation change

What you’re carrying forward

↗
Long records reveal patterns. A single unusual year is weather; repeated change across decades helps us see climate.
🍂
Seasons can tell different stories. Annual averages can hide changes that matter during the growing year.
🌧️🌡️
Climate evidence works together. Temperature and precipitation give a more useful picture when we consider them together.
