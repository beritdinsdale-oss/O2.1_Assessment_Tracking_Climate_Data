# Complete Weather and Climate Activity

Upload these files to the root of the GitHub Pages repository:

- `index.html`
- `app.js`
- `styles.css`

The activity now includes:

1. The Kaltura how-to video.
2. A live interactive Corvallis graph using RCC-ACIS/xmACIS data.
3. Four weather-versus-climate questions with feedback.
4. A final task asking learners to open xmACIS and explore another station.
5. Reflection fields for recording a weather observation and a climate pattern.

## Changing the video

In `index.html`, find:

`<!-- STEP 1 VIDEO: Replace only the src value below to use a different video. -->`

## Note about reflection fields

The Step 3 text fields are not saved or submitted. Learners should copy their
responses into Canvas or their course journal if required.
