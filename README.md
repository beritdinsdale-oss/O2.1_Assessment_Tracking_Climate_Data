# Reading Climate Stories in Weather Station Data

Redesigned GitHub Pages package for the climate/weather station activity.

## Learner flow
1. Welcome: distinguish a single year from a long record.
2. Watch the existing Kaltura weather-station demonstration.
3. Explore the live Corvallis annual average temperature record from RCC-ACIS.
4. Answer three short, page-like interpretation questions with feedback.
5. Open xmACIS, investigate a local station, and carry one observation into the Garden Observation Journal.

## Files
Upload `index.html`, `styles.css`, and `app.js` to the root of the existing repository, replacing the current versions.

## External links
- xmACIS: https://xmacis.rcc-acis.org/
- Garden Observation Journal: https://beritdinsdale-oss.github.io/garden-observation-journal/

## Accessibility
The activity includes keyboard-operable navigation, visible focus states, skip navigation, semantic headings, accessible form controls, status announcements, a tabular alternative to the chart, reduced-motion support, and text labels that do not rely on color alone.
