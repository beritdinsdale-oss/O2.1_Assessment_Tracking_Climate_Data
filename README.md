# Weather and Climate Activity

This package is ready for GitHub Pages or embedding in Canvas.

## Add your media

1. Rename your video file to `how-to-video.mp4` and place it in `assets/`.
2. Rename the Corvallis graph image to `corvallis-temperature-graph.png` and place it in `assets/`.
3. Open `index.html` and replace the sample transcript in the expandable transcript section.
4. Revise the graph alternative text so it accurately describes the dates, units, and broad trend in your final graph.

## Preview

Double-click `index.html`.

## GitHub Pages

Upload `index.html`, `styles.css`, `app.js`, and the `assets` folder to the repository root. Enable Pages from `main` and `/(root)`.

## Canvas embed

Host the activity on GitHub Pages, then add this in the Canvas HTML editor:

```html
<iframe src="https://USERNAME.github.io/REPOSITORY-NAME/" title="Weather and climate graph activity" width="100%" height="1800" loading="lazy"></iframe>
```

A normal link to the GitHub Pages activity is the safest fallback if your institution restricts iframes.

## Accessibility included

- Semantic headings, landmarks, fieldsets, and legends
- Keyboard operation and visible focus indicators
- Screen-reader announcements for feedback
- Video transcript section
- Descriptive graph alternative text placeholder
- Responsive design
- No time limits or drag-and-drop
- Immediate explanatory feedback
