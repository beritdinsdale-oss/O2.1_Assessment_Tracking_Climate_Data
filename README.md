# Corvallis xmACIS Interactive Activity

Upload these three files to the root of your GitHub Pages repository:

- index.html
- app.js
- styles.css

The page loads annual average temperature observations directly from the
RCC-ACIS data service used by xmACIS for station 351862, Corvallis State
University.

## How-to video

The video is in `index.html` under this comment:

`<!-- HOW-TO VIDEO: Replace only the src value below to use a different video. -->`

Replace only the URL inside the iframe's `src="..."` attribute.

The page needs internet access for both the xmACIS data and Chart.js.
