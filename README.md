# Tracking Climate Data

GitHub Pages-ready activity for Module 2.

## Upload these files directly to the repository root

- `index.html`
- `styles.css`
- `app.js`
- `README.md`

Do **not** upload the enclosing folder. When GitHub is correct, the repository homepage should show these files directly.

## Activity flow

1. Start — introduction to weather vs. climate patterns
2. Station — Kaltura demonstration
3. Graph — live Corvallis annual average temperature data
4. Pattern — three short interpretation questions
5. Local — learners open xmACIS, explore a nearby station, and record a finding in the Garden Observation Journal

## External links

- xmACIS: https://xmacis.rcc-acis.org/
- Garden Observation Journal: https://beritdinsdale-oss.github.io/garden-observation-journal/
