# Weather and Climate Activity

Upload these files to the root of your GitHub Pages repository:

- `index.html`
- `styles.css`
- `app.js`

The chart uses Chart.js from jsDelivr, so the published page needs internet access.

## Important

The temperatures in `app.js` are example values from the draft activity. Replace
them with verified Corvallis data before using the graph as an authoritative data source.
